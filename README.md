# Banking Analytics Power BI Project
A Sample Project on Churn rate in the Banking Sector

## Overview
This repository contains a comprehensive Power BI project focused on banking analytics and customer churn analysis. The project includes various data sets, Power BI reports, and supporting documentation for end-to-end business intelligence solutions.

## Features
- Customer Churn Analysis
- Dynamic Title Changes for Visuals
- Dynamic Measure Slicers
- Small Multiples Visualization
- Credit Card Usage Analysis
- Geographic Distribution Analysis
- Customer Demographics Analysis

## Data Sources
The project utilizes multiple data sources:
- Customer Information Database
- Active Customer Records
- Credit Card Transaction Data
- Geographic Distribution Data
- Customer Exit Records
- Demographic Data

## Tools Used
- Microsoft Power BI Desktop
- Excel for Data Storage
- CSV Data Files

## Installation & Setup
1. Clone this repository
2. Install Power BI Desktop (latest version recommended)
3. Open the .pbix files using Power BI Desktop
4. Ensure all data sources are properly connected

## Documentation
- Business requirements and specifications can be found in `RBC_BusinessRequirementDocument.docx`

## Using the Reports
Each .pbix file serves a specific purpose:
- `DynamicTitleChangeforVisuals.pbix`: Demonstrates dynamic title changes in visualizations
- `Interview_DynamicMeasureSlicer.pbix`: Shows implementation of dynamic measure slicers
- `SmallMultiplesinpowerBI.pbix`: Exhibits small multiples visualization technique
- `BANK_PROJ_UNFINISHED.pbix`: Main project file (work in progress)
